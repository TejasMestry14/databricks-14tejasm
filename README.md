# Databricks Course

Welcome! This repository contains all the source code used in the Databricks course.

## Contents

The source code in this repository covers hands-on examples and exercises for the course, organized by topic:

- **Notebooks** – Databricks notebooks for data engineering, SQL, and machine learning workflows.
- **Scripts** – Standalone Python and SQL scripts used throughout the lessons.
- **Data** – Sample datasets referenced in the examples.

## Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/<your-org>/<your-repo>.git
   cd <your-repo>
   ```

2. **Import into your Databricks workspace**

   - Open your Databricks workspace.
   - Navigate to **Repos** → **Add** → provide the Git URL.
   - Once imported, the notebooks and scripts will be available for you to run.

3. **Set up your compute**

   - Ensure you have access to a Databricks cluster or serverless compute.

## Prerequisites

- A Databricks workspace (Community Edition or a paid workspace).
- Basic familiarity with Python, SQL, and Spark.
- Databricks Runtime 14.x or later recommended.
